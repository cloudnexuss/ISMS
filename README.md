# ISMS Frontend

## Overview
This is the frontend for the Institute/Integrated Student Management System (ISMS). It provides a role-based user interface for students, faculty, directors, exam cell, and library staff.

## Tech Stack
- HTML5
- CSS3
- SVG/PNG/JPG assets

## Features
- Role-based dashboards (Student, Faculty, Director, Exam, Librarian)
- Academic management: grades, courses, timetable
- Administrative management: fees, grievances, notices
- Library management
- Responsive and visually appealing design

## Getting Started
Just open the relevant HTML file in your browser (e.g., `index.html` for login, `s_home.html` for student home, etc.).

## Folder Structure
- `s_*.html/css` - Student pages
- `f_*.html/css` - Faculty pages
- `d_*.html/css` - Director pages
- `e_*.html/css` - Exam cell pages
- `l_*.html/css` - Librarian pages
- `index.html` - Login page
- `*.svg/png/jpg` - Assets
